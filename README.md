## 这是什么

一个**单文件、零依赖、可离线运行**的演播室声学实时模拟器。

摆好音响、站好位置，它按真实物理实时算出这个房间的反射、驻波与混响，
直接送到你耳朵里。也可以把 QQ音乐 / 网易云 的声音接进来，
让它们在"浴室""音乐厅""配音间"里播放 —— 听差别，不是看图表。

> **20 字介绍**
> **把任意房间变成听音室，实时听到真实声学染色**

## ✨ 特性

### 声学模型（四层）

| 环节 | 方法 | 听感体现 |
|---|---|---|
| 早期反射 | **镜像声源法**（3 阶） | 换墙面材质，反射方向与音色立刻变 |
| 后期混响 | **FDN** 反馈延迟网络（8 条正交延迟线） | 平滑自然的混响尾巴 |
| 低频驻波 | **模态分解**（14 个特征模态滤波器） | 走到墙角低频"轰"起来 |
| 双耳定位 | **HRTF** | 耳机里能听出声音在身前还是身后 |

**反射低通**：每次反射额外衰减高频（表面粗糙度散射 + 边缘衍射），
截止频率随反射次数递减 —— 混响尾巴比早期反射更暗，这是真实房间的样子。

### 交互

- **8 种箱型**：书架箱 / 落地箱 / 近场监听 / 低音炮 / 吸顶喇叭 / 回音壁 / 便携蓝牙 / 号角
- **偏轴指向性**：高频随偏轴角收窄，低频全向 —— "皇帝位"存在的物理依据
- **20 种表面材料**：各自的六倍频程吸声系数
- **7 个预设场景**：配音间 / 控制室 / 演播室 / 客厅 / 浴室 / 音乐厅 / 车库
- **摆位按声学准则求解**，不是硬编码坐标 —— 换房间尺寸自动重算
- **顶部吸声云**：遮挡一阶顶面反射，治理顶棚颤动回声
- **啸叫检测**：实时频谱分析 + 接线风险评估，附治理建议
- **实时波形 / 频谱 / ETC** 示波器，带触发对齐
- **2D 平面图 + 3D 透视** 联动，可直接拖物体
- **延迟分解**：系统 / 空气传播 / 混响预延迟，堆叠条可视化

## 🚀 快速开始

### 方式 A：双击即用（推荐先试这个）

```
1. 下载 实时音频模拟.html
2. 双击，用 Chrome / Edge 打开
3. 点「▶ 启动音频引擎」
4. 戴上耳机
```

首屏已摆好 **5 只音响**，启动后自动播放粉红噪声，立刻能听到房间声学。

### 方式 B：部署到 GitHub Pages（推荐）

Pages 提供 `https://` 网址，属于**安全上下文** ——
「接入声卡」功能可直接可用，不需要任何本地启动脚本。

```
Settings → Pages → Source: Deploy from a branch → main / root
```

访问 `https://<用户名>.github.io/<仓库名>/` 即可。

### 方式 C：本地起服务（仅 Windows，想接外部音乐时）

```bat
Start.bat
```

> 需要这一步的原因：浏览器只在安全上下文允许访问音频输入，
> `file://` 会被拒绝。脚本起的是 `http://localhost`。
> 不联网、不装东西、不改系统设置。

## 🎵 接入自己的音乐

```
QQ音乐 ──▶ CABLE Input（设为该应用的输出）
                │
                ▼
         CABLE Output ──▶ 本软件捕获 ──▶ 房间声学染色 ──▶ 真实耳机
```

**三步**：

1. 装 **VB-CABLE**（vb-audio.com），**重启电脑**
2. Windows「应用音量和设备首选项」→ QQ音乐 → 输出设备改为 `CABLE Input`
3. 软件里 → 「🎚️ 声源 → 🔌 接入声卡」→ 输入设备选 `CABLE Output` → 开始捕获

⚠️ 输出设备**必须**指定为真实耳机，否则声音绕回来会啸叫。

**两个必开权限**：Windows 麦克风三项全开（含"让桌面应用访问麦克风"）、
浏览器弹窗点允许。

详见 [使用说明.md](使用说明.md)。

## 🔬 声学原理

信号链：

```
声源 ──┬─ 直达声 ──────────────── HRTF ──┐
       ├─ 早期反射（镜像声源 3 阶）─ 等功率声像 ─┤
       └─ 后期混响（FDN 8 线）────────────────┤
                                    低频模态染色 ┘──▶ 输出
```

- 直达声走 **HRTF** 保证定位精准
- 反射声用**等功率声像** —— 上百路 HRIR 卷积会拖垮 CPU
- 低频用**模态分解**重建驻波染色（几何声学的盲区）
- 每次反射施加**一阶低通**，截止频率随反射次数递减

### 关于精度

声学参数按真实物理公式计算：Eyring 混响公式、
镜像声源几何、空气吸收（温湿度相关）、ITU-R BS.775 摆位准则等。

客观指标（RT60 / C50 / C80 / D50 / DRR / ITDG / Ts / G）均可实时查看。

## ⚠️ 已知限制

**诚实说明**：

1. **外部音源捕获未做真机验证**
   开发环境中没有声卡与播放器，643 项测试均为静态逻辑校验
   （信号路由、声道分离、资源释放、错误分支、环路检测）。
   能保住逻辑正确，但**能否在你的机器上真的出声，需要实际验证**。

2. **未做真机听感校准**
   箱型参数是"典型听感模型"，不是某一具体型号的实测复刻。

3. **浏览器差异**
   仅在 Chromium 内核（Chrome / Edge）验证，Firefox / Safari 未测试。

4. **当前预设的地面统一为 50mm 吸音棉**
   这会大幅压低混响（浴室 2.51s → 0.17s）。
   想恢复原场景，见说明书 2.6 节的原地面对照表。
